# Directories

@ToSee => As the name says, pending files to sort out
Ability Cards => Project to print all Hero Upgrade Ability cards (frint and backs). has it's own readme file.
Alignment Grid => Project to generate a two sided PDF to test the alignment grid of tyour double sided printer
Assets => Some visual assets I needed to rebuild (probably deprecasted)
Back => Generation/download of card backs
Bounty Cards => Project to print of A5 bounty cards (cards that shows which creature is currently payin bounties).
Depth Event Chart => Project to have Depth Event chart in cards. It workd only in big cards. Too much text. Algo did tranlate to portuguese. (did not worked well)
Dividers => Project to print divider generator for cards (from BBG). Got from Internet and worked a better way to print (in my condition). After a long time, I just printed the originals. But in any case, the extracted files are there.
Fonts => Base fonts to install to use this templates
Gits => other SoB projects from Internet
Ideas => Image of ideas for game
Images => Image bank from Internet that I used (or not) in the creation of the game assets.
Math => small projects to understand tha math behing the game
Money => Project for money cards for SoB. The images I got from BBG, and made the PDFs to print double sided
Print Templates => templates to print cards in a way that you can fold & glue easly.
Resources => Resources I got from Internet. Most from BBG or from Virtual Tabletop home-made DLCs from Steam.
Rulebooks => Official rulebooks for the game (and translations)
XP Cards => Cards to track XP. I printed in printerstudio, a long tima ago.
